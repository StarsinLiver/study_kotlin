컬렉션과 여러가지 컬렉션 연산을 효율적으로 적용하면서 부가 비용을 많이 발생시키지 않는 대안인 시퀀스를 살펴보자

### 6.1 컬렉션에 대한 함수형 API

### 6.1.1 원소 제거와 변환 : filter 와 map

> filter

```kotlin
fun main() {
    val list = listOf(1, 2, 3, 4)
    list.filter { it > 2 }
}

// [3,4]
```

- filter 는 return 에 Boolean 타입을 제공해야 한다.

> map

```kotlin
fun main() {
    val list = listOf(1, 2, 3, 4)
    list.map { it * it }
}

// [1, 4, 9, 16]
```

걸러내거나 변환하는 연산이 원소의 값 뿐 아니라 인덱스에 따라서도 달라진다면 형제 함수인 filterIndexed 와 mapIndexed 를 사용할 수 있다.

> filterIndexed

```kotlin
fun main() {
    val list = listOf(1, 2, 3, 4)
    list.filterIndexed { index, element ->
        index % 2 == 0 && element > 3
    }
}
```

> mapIndexed

```kotlin
fun main() {
    val list = listOf(1, 2, 3, 4)
    list.mapIndexed  { index, element ->
        index + element
    }
}
```

맵의 경우 키와 값을 처리하는 함수가 따로 존재한다. filterKeys와 mapKeys는 키를 걸러내거나 변환하고, filterValues와 mapValues는 값을 걸러내거나 변환한다.

### 6.1.2 컬렉션 값 누적 : reduce와 fold

이 함수들은 컬렉션의 정보를 종합하는 데 사용한다. 즉, 원소로 이뤄진 컬렉션을 받아서 한 값을 반환한다. 이 값은 누적기 (accumulator)를 통해 점진적으로 만들어진다.

> reduce

```kotlin
fun main() {
    val list = listOf(1, 2, 3, 4)
    list.reduce { acc, element ->
        acc + element
    }
}
```

> fold

```kotlin
fun main() {
    val list = listOf(1, 2, 3, 4)
    list.fold("hello") { acc, element ->
        acc + element.toString()
    }
}

// hello1234
```

- fold 는 reduce와 비슷하지만 컬렉션 첫번째 원소를 누적값으로 시작하는 대신, 임의의 시작 값을 선택할 수 있다.

reduce나 fold 에서 중간 단계의 모든 누적값을 봅아내고 싶다면 runningReduce와 runningFold가 도움이 된다. fold와 reduce는 결괏값을 하나만 반환하지만 runningReduce와 runningFold는 리스트를 반환한다.

### 6.1.3 컬렉션에 술어 적용 : all, any, none, count, find

all 은 모든 원소가 이 술어를 만족한지를 묻는다.

> all

```kotlin
fun main() {
    val list = listOf(1, 1, 3, 4)
    list.all { it == 1 }
}
```

술어를 만족하는 원소가 하나라도 있는지 궁금하면 any를 쓴다.

> any

```kotlin
fun main() {
    val list = listOf(1, 2, 3, 4)
    list.any { it == 1 }
}
```

술어를 만족하는 원소가 아무것도 없는지 궁금하면 none을 쓴다.

> none

```kotlin
fun main() {
    val list = listOf(1, 2, 3, 4)
    list.none { it == 0 }
}
```

술어를 만족하는 원소의 개수를 알고 싶다면 count를 사용한다.

> count

```kotlin
fun main() {
    val list = listOf(1, 1, 3, 4)
    list.count { it == 1 }
}

// 2
```

술어를 만족하는 원소를 하나 찾고 싶으면 find 함수를 사용한다.

> find

```kotlin
data class Person (val name : String)

fun main() {
    val list = listOf(Person("A") , Person("B"), Person("C"))
    list.find { it.name.equals("A") }
}

// Person(name=A)
```

### 6.1.4 리스트를 분할해 리스트의 쌍으로 만들기

컬렉션을 어떤 술어를 만족하는 그룹과 그렇지 않은 그룹으로 나눌 필요가 있을 때가 있다. filter와 filterNot을 사용해 분리할 수 있지만 더 간결하게 처리할 수 있는 방법이 있다. 바로 partition 함수이다.

> partition

```kotlin
data class Person(val name: String, val age: Int)

fun main() {
    val list = listOf(Person("A", 21), Person("B", 19), Person("C", 13))
    var (comeIn, stayOut) = list.partition { it.age > 20 }

    println(comeIn)
    println(stayOut)
}

// comeIn : [Person(name=A, age=21)]
// stayOut : [Person(name=B, age=19), Person(name=C, age=13)]
```

### 6.1.5 리스트를 여러 그룹으로 이뤄진 맵으로 바꾸기 : groupBy

때에 따라서는 컬렉션의 원소들을 partition이 반환하는 '참'과 '거짓' 그룹으로만 분리할 수 없는 경우가 있다. 대신, 컬렉션의 원소를 어떤 특성에 따라 여러 그룹으로 나누고 싶을 수 있다. groupBy 함수가 이런 일을 할 수 있다.

> groupBy

```kotlin
data class Person(val name: String, val age: Int)

fun main() {
    val list = listOf(Person("A", 21), Person("B", 21), Person("C", 13))
    val result = list.groupBy { it.age }
    println(result)
}

// {21=[Person(name=A, age=21), Person(name=B, age=21)], 13=[Person(name=C, age=13)]}
```

이 연산의 결과는 컬렉션의 원소를 구분하는 특성이 키이고, 키 값에 따른 각 그룹이 값인 맵이다. 각 그룹은 리스트에 저장된다. 따라서 결과의 타입은 Map<Int, List<Person>> 이다.

다른 예로 맴버 참조를 활용해 문자열을 첫번째 글자에 따라 분류하는 코드도 만들 수 있다.

> gourpBy 와 멤버 참조 활용

```kotlin
fun main() {
    val list = listOf("Alice", "Abc", "Charlie")
    val result = list.groupBy(String::first)
    println(result)
}

// {A=[Alice, Abc], C=[Charlie]}
```

### 6.1.6 컬렉션을 맵으로 변환 : associate, associateWith, associateBy

원소를 그룹화하지 않으면서 컬렉션으로부터 맵을 만들어내고 싶다면 assciate 함수를 사용한다. associate에게 입력 컬렉션의 원소로부터 키/값 쌍을 만들어내느 람다를 제공한다.

> associate

```kotlin
fun main() {
    val list = listOf(Person("Alice", 21), Person("Abc", 21), Person("Charlie", 13))
    val result = list.associate { it.name to it.age }
    println(result)
}

// {Alice=21, Abc=21, Charlie=13}
```

associateWith는 컬렉션의 원래 원소를 키로 사용한다. 반대로 associateBy는 컬렉션의 원래 원소를 맵의 값으로 하고, 여러분의 람다가 만들어내는 값을 맵의 키로 사용한다.

> associateWith

```kotlin
fun main() {
    val list = listOf(Person("Alice", 21), Person("Abc", 21), Person("Charlie", 13))
    val result = list.associateWith { it.age }
    println(result)
}

// 원래 원소인 Person의 hashCode을 키로 활용하고, 람다의 값을 값으로 활용한다.
// {Person(name=Alice, age=21)=21, Person(name=Abc, age=21)=21, Person(name=Charlie, age=13)=13}
```

> associateBy

```kotlin
fun main() {
    val list = listOf(Person("Alice", 21), Person("Abc", 21), Person("Charlie", 13))
    val result = list.associateBy { it.age }
    println(result)
}

// 람다의 값을 키로 활용하고, 원래 원소를 값으로 활용한다.
// {21=Person(name=Abc, age=21), 13=Person(name=Charlie, age=13)}
```

### 6.1.7 가변 컬렉션의 원소 변경: replaceAll, fill

replaceAll 함수를 MutableList에 적용하면 여러분이 지정한 람다로 얻은 결과로 컬렉션의 모든 원소를 변경한다. 가변 리스트의 모든 원소를 똑같은 값으로 바꾸는 특별한 경우는 fill을 쓸 수 있다.

> replaceAll

```kotlin
fun main() {
    val list = mutableListOf("Alice", "Abc", "Charlie")
    list.replaceAll { it.uppercase() }
    println(list)
}

// [ALICE, ABC, CHARLIE]
```

> fill

```kotlin
fun main() {
    val list = mutableListOf("Alice", "Abc", "Charlie")
    list.fill("(redacted)")
    println(list)
}

// [(redacted), (redacted), (redacted)]
```

### 6.1.8 컬렉션의 특별한 경우 처리 : ifEmpty

컬렉션 입력이 비어있지 않은 경우, 즉 처리 대상이 될 원소가 있는 경우에만 처리를 계속하는 것이 타당한 경우가 자주 있다. ifEmpty 함수를 사용하면 컬렉션에 아무 원소도 없을 때 기본값을 생성하는 람다를 제공할 수 있다.

> ifEmpty

```kotlin
fun main() {
    val empty = emptyList<String>()
    val full = listOf("A", "B", "C")

    val result1 = empty.ifEmpty { listOf("A", "B", "C") }
    val result2 = full.ifEmpty { listOf("D", "E", "F") }

    println(result1)
    println(result2)
}

// result1 : [A, B, C]
// result2 : [A, B, C]
```

### 6.1.9 컬렉션 나누기 : chunked와 windowed

슬라이딩 윈도우를 생성하고자 windowed 함수를 사용할 수 있다. windowed 에 선택적으로 출력을 변환할 수 있는 람다를 전달할 수도 있다.

> windowed

```kotlin
fun main() {
    val temperatures = listOf(27.7, 29.8, 22.0, 35.5, 19.1)
    // sliding window 리스트 생성
    val result1 = temperatures.windowed(3)
    // sliding window 리스트 생성 시 출력을 변환
    val result2 = temperatures.windowed(3) { it.sum() / it.size }

    println(result1)
    println(result2)
}

// [[27.7, 29.8, 22.0], [29.8, 22.0, 35.5], [22.0, 35.5, 19.1]]
// [26.5, 29.099999999999998, 25.53333333333333]
```

입력 켈렉션에 대해 슬라이딩 윈도우를 실행하는 대신, 컬렉션을 어떤 주어진 크기의 서로 겹치지 않는 (서로소) 부분으로 나누고 싶을 때도 있다. chunked 함수가 이런 일을 한다.

> chuncked

```kotlin
fun main() {
    val temperatures = listOf(27.7, 29.8, 22.0, 35.5, 19.1)
    val result1 = temperatures.chunked(2)
    val result2 = temperatures.windowed(2) { it.sum() }

    println(result1)
    println(result2)
}

// [[27.7, 29.8], [22.0, 35.5], [19.1]]
// [57.5, 51.8, 57.5, 54.6]
```

### 6.1.10 컬렉션 합치기: zip

때로 연관이 잇는 데이터가 들어있는 별도의 두 리스트를 한꺼번에 종합해야할 때가 있다.

각 리스트의 값들이 서로의 인덱스에 따라 대응된다고 알고 있다면, zip 함수를 사용해 두 컬렉션에서 간은 인덱스에 있는 원소들의 쌍으로 이뤄진 리스트를 만들 수 있다.

> zip

```kotlin
data class Person(val name: String, val age: Int)

fun main() {
    val names = listOf<String>("Alice", "Joe", "Mary")
    val ages = listOf<Int>(22, 31, 44, 0, 2, 3)
    val result1 = names.zip(ages)
    val result2 = names.zip(ages) { name, age -> Person(name, age) }

    println(result1)
    println(result2)
}

// [(Alice, 22), (Joe, 31), (Mary, 44)]
// [Person(name=Alice, age=22), Person(name=Joe, age=31), Person(name=Mary, age=44)]
```

결과 컬렉션의 길이는 두 입력 컬렉션 중 더 짧은 쪽의 길이와 같다는 점에 유의하자 zip은 두 입력 컬렉션 모두에 원소가 들어있는 인덱스에 해당하는 원소들만 처리한다.

Pair 객체를 생성하는 to 함수와 마찬가지로 zip ㅎ마수도 중위 표기법으로 호출이 가능하지만 중위 표기법을 쓸때는 람다를 전달할 수 없다.

> zip 을 중위 표기법으로 사용하기

```kotlin
fun main() {
    val names = listOf<String>("Alice", "Joe", "Mary")
    val ages = listOf<Int>(22, 31, 44, 0, 2, 3)
    println(names zip ages)
}

// [(Alice, 22), (Joe, 31), (Mary, 44)]
```

### 6.1.11 내포된 컬렉션의 원소 처리 : flatMap과 flatten

flatMap 함수를 사용하면 라이브러리의 모든 집합을 계산하되 추가적인 내포가 없이 계산할 수 있다.

flatMap이 하는 일은 2가지다. 우선 컬렉션의 각 원소를 파라미터로 주어진 함수를 사용해 변환(또는 매핑)한다. (map함수가 하는 일과 같다.) 그 후 변환한 결과를 하나의 리스트로 합치는 것을 flatMap이 펼치는 것은 flatten이 해준다.

> flatMap

```kotlin
fun main() {
    val library: List<Library> = listOf<Library>(
        Library("Lee", listOf("Book1" , "Book2" , "Book3")),
        Library("Chang", listOf("Book4" , "Book5" , "Book6"))
    )

    val result = library.flatMap { it.books }
    println(result)
}

// [Book1, Book2, Book3, Book4, Book5, Book6]
```
