### 5.4 수신 객체 지정 람다 : with, apply, also

이번 절은 코틀린 표준 라이브러리의 with, apply, also를 보여준다.

수신 객체를 명시하지 않고 람다의 본문 안에서 다른 객체의 메서드를 호출할 수 있게 하는 것이다. 그런 람다를 수신 객체 지정 람다 (lambda with receiver)라고 부른다.

### 5.4.1 with 함수

with 절의 예제를 한번 보자 예제를 리펙터링 해보자

> 예시 : 알파벳 만들기

```kotlin
fun alphabet(): String {
    val result = StringBuilder();
    for (letter in 'A'..'Z') {
        result.append(letter)
    }
    result.append("\nNow I know the alphabet!")
    return result.toString()
}

fun main() {
    println(alphabet())
}
```

이 예제에서 result 에 대해 다른 여러 메서드를 호출하면서 매번 result 라는 이름을 반복 사용했다. 다음은 withfh ektl Tms rufhrkdlek.

> with를 사용해 알파벳 만들기

```kotlin
fun alphabet(): String {
    val stringbuiler = StringBuilder();
    return with(stringbuiler) {
        for (letter in 'A'..'Z') {
            this.append(letter)
        }
        this.append("\nNow I know the alphabet!")
        this.toString()
    }
}

fun main() {
    println(alphabet())
}
```

with 문은 언어가 제공하는 특별한 구문처럼 보인다. 하지만 실제로는 파라미터가 2개 있는 함수다. 이 경우 첫번째 파라미터는 stringbuiler, 두번째 파라미터가 람다다.

with 함수는 첫번째 인자로 받은 객체를 두번째 인자로 받은 람다의 수신객체로 만든다. 람다 안에서는 명시적인 this 참조를 사용해 그 수신 객체에 접근할 수 있다. 또한 this. 를 생략할 수 있다.

앞의 alphabet 함수를 한번 더 리펙터링해서 불 필요한 stringbuiler 변수를 없앨 수도 있다.

> with 변수 stringbuilder 제거

```kotlin
fun alphabet(): String {
    return with(StringBuilder()) {
        for (letter in 'A'..'Z') {
            append(letter)
        }
        append("\nNow I know the alphabet!")
        toString()
    }
}
```

### 5.4.2 apply 함수

apply 함수는 거의 with 와 동일하게 동작한다. 유일한 차이는 apply는 항상 자신에 전달된 객체 (즉, 수신 객체)를 반환한다는 점 뿐이다.

> apply를 사용해 알파벳 만들기

```kotlin
fun alphabet(): String = StringBuilder().apply {
    for (letter in 'A'..'Z') {
        append(letter)
    }
    append("\nNow I know the alphabet!")
}.toString()
```

apply를 임의의 타입의 확장 함수로 호출할 수있다.

apply를 객체 초기화에 활용하는 예로 안드로이드의 TextView 컴포넌트를 만들면서 속성 중 일부를 설정해보자

> 객체 초기화에 사용된 apply

```kotlin
fun createViewWithCustomAttributes(context: Context) {
    TextView(context).apply {
        text = "Sample Text" ,
        textSize = 20.0
        setPadding(10, 0, 0, 0)
    }
}
```

with 와 apply는 수신 객체 지정 람다를 사용하는 일반적인 예 중 하나다. 더 구체적인 함수를 비슷한 패턴으로 활용할 수 있다. 예를 들어 표준 라이브러리의 buildString 함수를 사용하면 alphabet 함수를 더 단순화할 수 있다.

> buildString 을 사용해 알파벳 만들기

```kotlin
fun alphabet() = buildString {
    for (letter in 'A' .. 'Z')
        append(letter)
    append("\nNow I know the alphabet!")
}
```

코틀린 표준 라이브러리에는 읽기 전용 List, Set, Map을 생성하지만 생성과정에서는 가변 컬렉션인 것처럼 다루고 싶을 때 도움이 되는 컬렉션 빌더 함수가 들어 있다.

> buildList, buildSet, buildMap 예제

```kotlin
val a = buildList {
    addAll(listOf(1, 2, 3))
    add(3)
    add(index = 0, element = 3)
}

val b = buildSet {
    add("Apple")
    addAll(listOf("Apple", "Banana"))
}

val c = buildMap<String, Int> {
    put("Gold", 1)
    putAll(listOf("Silver" to 2, "Bronze" to 3))
}
```

### 5.4.3 객체에 추가 작업 수행

apply와 마찬가지로 also ㅎ마수도 수신 객체를 받으면, 그 수신 객체에 대해 어떤 동작을 수행한 후 수신 객체를 돌려준다.

주된 차이는 also의 람다 안에서는 수신 객체를 인자로 참조한다는 점이다. 따라서 파라미터 이름을 부여하거나 디폴트 이름인 it를 사용해야한다.

> also를 사용해 효과를 추가로 적용

```kotlin
val list = listOf("Apple", "Banana", "Cherry")
val mutablelist = mutableListOf<String>()
list.map { it.uppercase() }
    .also { mutablelist.addAll(it) }
    .filter { it.length > 5 }
    .also { println(it) }
    .reversed()
```
