### 7.8 let 함수

let 함수를 사용하면 널이 될 수 있는 식을 더 쉽게 다룰 수 있다. let 함수를 안전한 호출 연산자와 함께 사용하면 원하는 식을 평가해서 결과가 null인지 검사한 다음에 그 결과를 변수에 넣는 작업을 간단한 식을 사용해 한꺼번에 처리할 수 있다.

let을 사용하는 가장 흔한 용례는 널이 될 수 있는 값을 널이 아닌 값만 인자로 받는 함수로 넘기는 경우다.

> let 을 사용하지 않았을 경우

```kotlin
fun sendEmailTo(email: String) {
    /* ... */
}

fun main() {
    val email: String? = "foo@bar.com"
    if (email != null) sendEmailTo(email)
}
```

하지만 let 함수를 통해 인자를 전달할 수도 있다. let 함수는 자신의 수신 객체를 인자로 전달받는 람다에 넘긴다. 널이 될 수 있는 값에 대해 안전한 호출 구문을 사용해 let을 호출하되 널이 아닌 타입을 인자로 받는 람다를 let에 전달한다. 이렇게 하면 널이 될 수 있는 타입의 값을 널이 될 수 없는 타입의 값으로 바꿔 람다에 전달하게 된다.

let 함수는 널이 아닌 경우에만 호출된다. 따라서 위 예제를 다음으로 바꿔 사용할 수 있다.

> let 을 사용했을 경우

```kotlin
fun sendEmailTo(email: String) {
    /* ... */
}

fun main() {
    val email: String? = "foo@bar.com"
    email?.let { email -> sendEmailTo(email) } // null 이 아니라면 호출됨
}
```

email?.let { sendEmailTo(it) } 처럼도 가능하다.
