### 9.3 컬렉션과 범위에 대해 쓸 수 있는 관례

컬렉션을 다룰때 가장 많이 쓰는 연산은 인덱스를 사용해 원소를 읽거나 쓰는 연산과 어떤 값이 컬렉션에 속해 있는지 검사하는 연산이다. a[b]라던가 in 연산자라던가 이런 연산을 지원하고자 어떤 관례를 사용하는지 살펴보자

### 9.3.1 인덱스로 원소 접근 : get과 set

코틀린에서 맵에 접근할 때 자바 배열 원소에 접근할 대처럼 각괄호 ([])를 사용한다.

```kotlin
val value = map[key]
```

같은 연산자를 사용해 변경 가능한 맵에서 어떤 키에 대한 값을 변경할 수 있다.

```kotlin
mutableMap[key] = newValue
```

코틀린에서는 인덱스 접근 연산자도 관례를 따른다. 인덱스 접근 연산자를 사용해 원소를 읽는 연산은 get 연산자 메서드로, 원소를 쓰는 연산은 set 연산자 메서드로 변환된다. Map과 MutableMap인터페이스에는 두 메서드가 이미 들어가 있다.

> get 관례 구현하기

```kotlin
class Point(val x: Int, val y: Int)

operator fun Point.get(index: Int) : Int {
    return when (index) {
        0 -> x
        1 -> y
        else -> throw IndexOutOfBoundsException("INvalid coordinate $index")
    }
}

fun main() {
    val p = Point(10, 20)
    println(p[1])
}

// 20
```

get이라는 메서드를 만들고 operator 변경자를 붙이기만 하면된다. 또는 2차원행렬일 경우 operator fun get(rowIndex:Int, colIndex: Int)를 정의하면 matrix[row, col]로 그 메서드도 호출할 수 있다.

> set 구현하기

```kotlin
data class MutablePoint(var x: Int, var y: Int)

operator fun MutablePoint.set(index: Int,  value : Int) {
    when (index) {
        0 -> x = value
        1 -> y = value
        else -> throw IndexOutOfBoundsException("INvalid coordinate $index")
    }
}

fun main() {
    val p = MutablePoint(10, 20)
    p[1] = 30
    println(p)
}

// MutablePoint(x=10, y=30)
```

### 9.3.2 어떤 객체가 컬렉션에 들어있는지 검사 : in 관례

컬렉션이 지원하는 다른 연산자로는 in이 있다. in은 객체가 컬렉션에 들어있는지 검사(membership test, 멤버십 검사)한다. 이때 대응하는 함수는 contains다.

> in 관례 구현하기

```kotlin
data class Rectangle(val upperLeft: Point, val lowerRight: Point)

operator fun Rectangle.contains(p: Point): Boolean {
    return p.x in upperLeft.x..<lowerRight.x &&
            p.y in upperLeft.y..<lowerRight.y
}

fun main() {
    val rect = Rectangle(Point(10, 20), Point(30, 40))

    println(Point(20, 30) in rect)
    println(Point(5, 5) in rect)
}

// true
// false
```

Rectangle.contains 구현에서 ..< 연산자를 사용해 열린 범위 (open range)를 만들고, in 연산자를 사용해 속하는지 검사한다.

- 열린 범위는 긑값을 포함하지 않는 범위를 말한다.
- 10 .. 20이라는 식을 사용해 닫힌 범위를 만들면 10 이상 20 이하인 범위가 생긴다.
- 10 ..< 20 으로 만드는 열린 범위는 10 이상 19 이하인 범위이며, 20은 범위 안에 속하지 않는다.

### 9.3.3 객체로부터 범위 만들기 : rangeTo와 rangeUntil 관례

범위를 만들려면 .. 구문을 사용해야 한다. 예를 들어 1..10은 1부터 10까지 모든 수가 들어있는 범위를 가리킨다. .. 연산자는 rangeTo 함수 호출을 간략하게 표현하는 방법이다.

> 두 개의 구문은 같은 구문이다.

```kotlin
start..end
start.rangeTo(end)
```

ragneTo 함수는 범위를 반환한다. 우리의 클래스에 대해서도 이 연산자를 정의할 수 있다. 하지만 어떤 클래스가 Comparable 인터페이스를 구현하면 rangeTo를 정의할 필요가 없다.

코틀린 표준 라이브러리를 통해 비교 가능한 원소로 이뤄진 범위를 쉽게 만들 수 있다. 코틀린 표준 라이브러리에는 모든 Comparable 객체에 대해 적용 가능한 rangeTo 함수가 들어있다.

```kotlin
operator fun <T : Comparable<T>> T.rangeTo(that : T): ClosedRange<T>
```

이 함수는 범위를 반환하며 어떤 원소가 그 범위 안에 있는지 검사할 수 있게 해준다.

> 예제 : LocalDate를 사용해 날짜의 범위를 만들기

```kotlin
import java.time.LocalDate

fun main() {
    val now = LocalDate.now()
    val vacation = now..now.plusDays(10)
    println(now.plusWeeks(1) in vacation)
}

// true
```

now..now.plusDays(10)이라는 식은 컴파일러에 의해 now.rangeTo(now.plusDays(10)) 으로 변환된다. rangeTo 함수는 LocalDate의 멤버는 아니며 앞에서 살펴본대로 Comparable에 대한 확장 함수다.

rangeTo 연산자는 다른 산술 연산자보다 우선순위가 낮다. 하지만 혼동을 피하기 위해 괄호로 인자를 감싸주면 더 좋다.

```kotlin
val n = 9
println(0..(n + 1))
```

또한 0..n.forEach {} 와 같은 식은 컴파일할 수 없음에 유의하라. 범위 연산자는 우선순위가 낮아 버무이의 메서드를 호출하려면 범위를 괄호로 둘러싸야한다.

```kotlin
val n = 9
(0..n).forEach { println(it) }
```

rangeTo 연산자와 비슷하게 rangeUntil 연산자 (..<)는 열린 범위를 만든다. 열린 범위는 상계 값을 포함하지 않는다.

> rangeUntil

```kotlin
fun main() {
    (0..<9).forEach { print(it) }
}

// 012345678
```

이제 컬력션이나 범위를 이터려이션할 때 사용하는 관례를 살펴보자

### 9.3.4 자신의 타입에 대해 루프 수행 : iterator 관례

코틀린의 for 루프는 범위 검사와 똑같이 in 연산자를 사용한다. 하지만 이 경우 in의 의미는 다르다. for (x in list) { ... }와 같은 문장은 list.iterator()를 호출해서 이터레이터를 얻은 다음, 이터레이터에 대해 hasNext와 next 호출을 반복하는 식으로 변환된다.

하지만 코틀린에서는 이 또한 관례이므로 iterator 메서드를 확장 함수로 정의할 수 있다. 이런 성질로 인해 일자 자바 문자열에 대한 for 루프가 가능하다. 코틀린 표준 라이브러리는 String의 상위 클래스인 CharSequence에 대한 iterator 확장 함수를 제공한다.

````kotlin
// 이 라이브러리 함수는 문자열을 이터레이션 할 수 있게 도와준다.
operator fun CharSequence.iterator(): CharIterator
```

> CharSequence.iterator 사용

```kotlin
fun main() {
    for (c  in "abc") { }
}
```
````

우리가 클래스안에 직접 iterator 메서드를 구현하거나, 우리가 사용하는 서드파티 클래스에 구현할 수도 있다.

```kotlin
import java.time.LocalDate

operator fun ClosedRange<LocalDate>.iterator(): Iterator<LocalDate> =
    object : Iterator<LocalDate> {
        var current = start
        override fun hasNext(): Boolean =
            current <= endInclusive

        override fun next(): LocalDate {
            val thisDate = current
            current = current.plusDays(1)
            return thisDate
        }
    }

fun main() {
    val newYear = LocalDate.ofYearDay(2042, 1)
    val daysOff = newYear.minusDays(1)..newYear
    for (dayOff in daysOff) {
        println(dayOff)
    }
}

// 2041-12-31
// 2042-01-01
```
